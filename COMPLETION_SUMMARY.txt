Create .env.local file in root directory with these variables.

================================================================================
                          IMPORTANT NOTES
================================================================================

1. JWT Authentication
   - Backend sets JWT in HTTP-only cookie
   - Frontend automatically sends with requests
   - API client handles this automatically

2. Form Validation
   - Frontend validates before API call
   - Backend should validate again
   - Errors displayed to user

3. Exam Selection
   - One-time, irreversible action
   - Cannot be changed after selection
   - Admin only capability for changes

4. Feedback Form
   - Authentication required (redirects to /login if not auth'd)
   - Only available to signed-in users
   - Sends to POST /api/feedback endpoint

5. Legal Pages
   - Content provided as starting point
   - Should be reviewed and customized
   - Important for compliance

6. API Endpoints
   - 6 endpoints implemented in client
   - All use JWT authentication via cookies
   - Error handling included
